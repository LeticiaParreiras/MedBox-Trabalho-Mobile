# Rota Farmacia
## Rodando 
1. Instale dependências

   ```bash
   npm install
   ```

2. Inicie o aplicativo:

   ```bash
   npx expo start
   ```
   caso precise rode com tunnel: 
   ```bash
   npx expo start --tunnel
   ```
